# Splash robot artwork

Generated with the built-in `image_gen` tool, with `transparent_background: true`.
The selected PNG is bundled at `assets/images/splash_robot.png`.
The greeting is rendered separately in Flutter using the requested “Wellcome” wording.
The raised hand is animated at runtime with a wrist-anchored image mesh; the
original PNG remains the source artwork. The wave eases in and out and follows
the application's reduced-motion setting.

## Final generation prompt

Use case: stylized-concept. Asset type: transparent character illustration for the welcome splash screen of a Flutter developer portfolio app. Primary request: one friendly modern robot holding a modern smartphone and greeting the visitor. Style: premium polished 3D character render, soft rounded industrial design, white ceramic body with brushed silver joints, dark glass face, friendly smiling luminous cyan eyes, restrained electric-blue accents matching a clean modern mobile app. Full-body robot floating gently, facing viewer in a slight three-quarter pose, oversized friendly head, compact body, rounded feet. One hand visibly grips a slim large modern edge-to-edge smartphone beside its body, with a dark screen and a simple glowing blue abstract app interface; the other hand raised in a welcoming wave. Clear readable silhouette at small mobile sizes, soft studio lighting, subtle blue rim light, charming and sophisticated. Centered square composition with comfortable transparent space around the entire robot including waving hand, antenna, feet and phone. Genuine transparent background and clean alpha edges, no backdrop, no ground plane. No text, no lettering, no speech bubble, no logos, no watermark; the welcome greeting will be rendered separately in the application for crisp localized typography.
